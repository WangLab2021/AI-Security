# ADAPTIVE FLDP

**We propose an adaptive privacy-preserving federated learning （Adp-PPFL） framework, which safeguards the FL from gradient leakage attacks.**


**We support **[PyTorch](https://github.com/WangLab2021/AI-Security/blob/main/Data%20Privacy/AdaFLDP_Open/Adaptive_FLDP.py)·[PaddlePaddle](https://github.com/WangLab2021/AI-Security/tree/main/Data%20Privacy/AdaFLDP_Open/AdaFLDP_PaddlePaddle)·[MindSpore](https://github.com/WangLab2021/AI-Security/tree/main/Data%20Privacy/AdaFLDP_Open/AdaFLDP_MindSpore)·[Tensorflow](https://github.com/WangLab2021/AI-Security/tree/main/Data%20Privacy/AdaFLDP_Open/AdaFLDP_TensorFlow)****
